## Project Overview

This repository contains the Master's thesis developed for the **M.Sc. in Probability and Statistics** at CIMAT. The research focuses on a modified 
$\Lambda$-Wright-Fisher population model that incorporates multi-type frequency-dependent selection mechanisms, as well as both extreme and non-extreme reproductive events, which are modeled through coloring rules.

The thesis also investigates the scaling limits of the discrete process, leading to a limiting stochastic differential equation (SDE). Under a vanishing-noise assumption, a qualitative analysis of the deterministic component of the limiting process is carried out for specific examples of selection functions. Additionally, numerical solvers and stochastic simulations are implemented in Python to investigate the behavior of the limiting SDE.


## Repository Contents

- **`thesis/` (PDF):** Complete Master's thesis manuscript covering the theoretical framework, scaling limit proofs, qualitative analysis, and numerical experiments.
- **`code/`:** Python scripts implementing the numerical solvers and stochastic simulations of the limiting SDE.
